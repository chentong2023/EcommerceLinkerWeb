# EcommerceLinker Web Demo
页面信息架构与产品定位制作的原创多页面前端原型，不直接复制原站品牌、代码、图片或逐字文案。

## 页面
- index.html：首页 / Hero / 产品价值 / 功能 / 客户案例 / FAQ / CTA
- features.html：核心能力详情
- solutions.html：解决方案与渠道
- pricing.html：示例方案页

- assets/css/style.css：统一响应式 CSS
- assets/js/app.js：移动菜单、FAQ 折叠、平滑滚动

## 定价页面
包含三个动态定价卡片：
1. 免费版本：€0 / 1个月
2. 基础版本：示例 €1,980 / 6个月，提供部署与支持
3. Plus版本：示例 €3,600 / 1年，提供全套服务

交互：卡片悬浮 3D 动效、方案选择反馈、方案/详细对比切换、响应式移动端。
价格为示例值，可直接修改 HTML 中的金额。
